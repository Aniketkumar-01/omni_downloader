# Security Policy

## Supported Versions

Only the latest release of OmniDownloader receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.4.x   | :white_check_mark: |
| < 1.4.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within OmniDownloader, please do not file a public issue on GitHub.

Instead, please report the vulnerability privately via:
- **GitHub Security Advisories**: Navigate to the [Security Advisories](https://github.com/Aniketkumar-01/omni_downloader/security/advisories/new) page of the repository and click "Report a vulnerability".
- **Email**: Send detailed reproduction steps and impact to the repository maintainer.

### What to Include
- Detailed description of the vulnerability.
- Steps or a proof-of-concept (PoC) to reproduce the issue.
- Impact assessment (e.g. local privilege escalation, arbitrary code execution, token leakage).

All legitimate security reports will be acknowledged within 48 hours, and a security patch will be prioritized and published in a subsequent release.
